# systemlab

systemlab is a React 19 + TypeScript + Vite single-page app.

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Run lint, typecheck, architecture check and tests (the same checks as CI):

```bash
npm run verify
```
